# PercEF project-fair poster

`PercEF_poster.pptx` follows the PES University project-fair template (20 x 11.25 in, Canva
original: `E:\shenvipranav\Project Fair Poster Template.pdf`). It is generated by
`build_poster.js` but is meant to be edited by hand in PowerPoint (or Google Slides / Canva import).

## Editing in PowerPoint
- **Add a photo** (members, guide): click the grey "Photo" frame -> right-click -> *Format Shape* ->
  *Fill* -> *Picture or texture fill* -> *Insert...* -> choose the photo. The photo takes the frame's
  shape and size. Then delete the word "Photo" inside the frame.
- **Names / SRNs**: click the text next to each frame and type.
- **Any text**: click and edit. Every object is named in the Selection Pane (Home -> Arrange ->
  Selection Pane), e.g. "Methodology text", "Stat 2 number", "Arch: probe".
- **Architecture diagram**: boxes and arrows are normal shapes; drag, recolour or retype them.
- **Results figure**: right-click -> *Change Picture* to swap in a newer figure
  (`server_results/paper_out_<latest>/fig2_p1_vs_ks.png`).
- **Centre name**: the subtitle says CDSAML; change it to CCBD if that is your centre (the template
  shows both).
- **Print/share**: File -> Export -> PDF.

## Regenerating from the script
    cd poster && npm install && node build_poster.js            # writes PercEF_poster.pptx
Regenerating overwrites manual edits, so either edit the text in `build_poster.js` and regenerate,
or edit the .pptx by hand from now on, not both.
